ENVIO PARA O GITHUB

Envie Site-exemplo/, versoes/ e README.md. Se usar git no terminal:

  git add README.md Site-exemplo versoes
  git commit -m "Documenta versao 1.0.1 do app de OS"
  git push

Nao envie dados reais de clientes ou anexos de ordens ao repositorio.
